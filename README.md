# MarioPatterns 🎮

> A 2D Mario-inspired platformer game built in Java (Eclipse), designed to demonstrate the practical implementation of core Object-Oriented Design Patterns.

## Design Patterns Implemented

| Pattern | Usage in Game |
|---------|--------------|
| **Singleton** | Game manager — ensures a single instance controls the game loop |
| **Observer** | Event system — notifies components on player actions (jump, collision, score) |
| **Factory** | Entity creation — generates enemies, blocks, and items dynamically |
| **Strategy** | Movement behaviors — swappable movement algorithms for different enemies |
| **State** | Player states — manages transitions between idle, running, jumping, dead |

| Layer | Technology |
|-------|-----------|
| Language | Java |
